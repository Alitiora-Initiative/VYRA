# Security policy

## Supported versions

Security fixes are applied to the default branch.

## Reporting a vulnerability

Do not publish exploit details, credentials, personal data or a working attack against a live system in a public issue. Use GitHub's private **Report a vulnerability** flow for this repository when it is enabled. Include the affected commit, impact, reproducible steps and any suggested mitigation.

## Safety boundary

VYRA is a paper-first software foundation. Do not submit real broker credentials, wallet seed phrases, private keys, client money data or identity documents through issues or pull requests. Live execution and deposits/withdrawals are disabled.
