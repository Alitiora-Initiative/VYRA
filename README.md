# VYRA

VYRA is a multi-asset brokerage platform foundation. It is an engineering prototype and is **not** a licensed broker or financial service.

## Initial scope
- Web brokerage console (Next.js)
- Portfolio, watchlists and market data provider adapters
- Orders, risk checks and audit trail architecture
- Paper execution initially; live execution remains gated behind provider, compliance, safety and certification requirements
- Multi-asset architecture for crypto, equities, FX and commodities

See `docs/ARCHITECTURE.md` and `docs/ROADMAP.md`.
